# gatoccino

Página web de una cafetería temática con café, postres y michis. Incluye catálogo de productos, secciones de experiencias, servicios y eventos, y una sección demostrativa de adopción responsable.

Abre `index.html` en un navegador para ver el sitio. Los estilos están en `style.css` y `script.js` muestra el catálogo de bebidas y postres, los perfiles ilustrativos de gatitos y las actividades de eventos. Las fechas, horarios, precios y cupos de los eventos están pendientes de confirmación y se editan en `gatoccinoEvents`. El formulario de adopción es una demostración local que no envía ni guarda datos. El formulario de eventos prepara un correo a `hola@gatoccino.com` para que la persona lo revise y lo envíe; no confirma reservas.
