# gatoccino

Página web de una cafetería temática con café, postres y michis. Incluye catálogo de productos y una sección demostrativa de adopción responsable.

Abre `index.html` en un navegador para ver el sitio. Los estilos están en `style.css` y `script.js` muestra el catálogo de bebidas y postres, y los perfiles ilustrativos de gatitos. Los precios son sugeridos en bolivianos. El formulario de adopción es una demostración local y no envía ni guarda datos.
